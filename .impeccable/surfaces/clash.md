# SOCKS5 订阅转换 /clash/

Mode: Operate.

继承 GetToken 的深色背景、系统中文字体、蓝色链接、白色主按钮、8px 表单圆角和 16px 工作区圆角。沿用全站八项导航，以“订阅转换”替换原“住宅IP”导航项；入口同时放在住宅 IP 页与共用页脚，不新增品牌或远程字体。

任务：用户批量粘贴 SOCKS5 链接、IP:端口:账号:密码或无认证的 IP:端口，生成可拉取的 Clash YAML 订阅，复制链接或唤起客户端，也可在本机下载文件。最多 100 个代理，包含 IPv6、名称、百分号编码与可选 UDP。错误定位到行，输入和错误提示不通过 URL 或日志传递。

电脑采用左侧输入、右侧订阅与 YAML 预览的两栏工作区；900px 以下堆叠，生成后将订阅滚入视图。空态直接显示格式说明；无 API 时保留本地下载。控件有标签、键盘焦点、加载和失败状态。示例仅使用文档保留地址。

生成前说明：本站加密保存配置 30 天，链接持有人能读取凭据。每次生成是一份快照，重新生成会撤销本页上一个链接；可主动使链接失效。刷新后的旧链接保留至到期，客户端已下载配置需自行删除。

系统文件复核：clash.css 使用 guides.css 与 chrome.css 的既有颜色、字体和圆角；不改 DESIGN.md 或 design.json。原有系统显示字体为继承视觉，不在本次扩展中重新定义。
