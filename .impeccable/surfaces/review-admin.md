# 审核后台 /verify/admin/

Mode: Operate.

继承 PRODUCT.md、DESIGN.md 和现有 verify.css 的深色视觉、字体、白色与幽灵按钮，不改用户提交页的布局和侧栏。

目标：管理员登录后找到待审核提交，按编号或 Key 末四位搜索，查看凭据并复制，填写用户可见说明，确认通过或未通过；用户在原私密查询入口看到结果。

仅 Key 模式使用四个状态筛选和四项现有口径统计；历史淘宝和财务记录保持可查。列表打码、详情按需读取完整值。错误、空列表、取消确认、请求失败、会话过期均有明确状态；刷新保留详情输入。预计时长由共用规则提供，超时不自动判定。

电脑使用原有列表 / 详情两栏；手机沿用单栏，表格在自己的区域滚动，选中记录滚到详情，输入框有可见标签。无新品牌、外部字体或动态效果。

验证：桌面和手机一起检查，修复一批已发现问题，再确认一轮；不继续循环美化。
