# 询价与支付测量口径

本轮只交付口径与运营登记要求，尚未接入第三方分析平台。没有真实渠道数据，不能给出转化率、排名或流量提升结论。

| 阶段 | 建议事件 | 事实来源 | 不能代替的结果 |
| --- | --- | --- | --- |
| 进入公开落地页 | landing_view | 后续经确认的分析服务或脱敏访问统计 | 不等于有购买意向 |
| 选择商品方案 | plan_select | 客户端明确操作 | 不等于可供货 |
| 打开有效咨询 | inquiry_start | 可受理状态下主动联系 | 点击不等于咨询被收到 |
| 有效询价 | inquiry_received | 支持方登记并能定位请求 | 不等于已报价 |
| 提供书面报价 | quote_sent | 人工登记的报价与有效期 | 不等于成交 |
| 普通商品成交 | sale_confirmed | 经核对的收款和交付登记 | 不使用浏览器备注码作为证据 |
| 审核付款 | verify_payment_confirmed | 服务端验签或查单后的 paid 事实 | 不使用二维码展示、按钮点击或用户口述 |
| 审核退款完成 | verify_refund_confirmed | 支付平台确认的退款及原账户核对 | 申请已受理不等于退款到账 |

公共事件候选字段仅包括规范公开路由、产品键、档位键、意向周期、受理状态、获客渠道的受控分类；不记录 Session Key、API Key、密码、查询凭据、完整 URL query/fragment、付款信息或用户提交的任意文本。

人工登记与财务系统可在受控内部范围使用自己的记录编号；公开分析不得直接上报能恢复私人订单的标识。去重按真实来源和事件处理，服务端重复通知不会重复计为成交。分析工具选型、授权及数据保留确认后再实施采集，不以完成本文代表埋点已上线。
