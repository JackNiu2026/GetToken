    Claude KYC常见问题

    Claude 官方 KYC需要准备什么？

    官方通过 Persona 验证身份，需要有效的政府签发实体照片证件，可能还需用手机实时自拍。请按 Claude 账户内提示由本人完成；Session Key 是登录凭据，不能替代身份证件或完成官方身份认证。

    提交后什么时候开始处理？

    先人工核对淘宝订单及购买内容，核单通过后开始处理，预计 24 小时。超时仍显示处理中，不会自动判定通过；官方状态以 Claude 账户显示为准。

    需要在这里付款或上传截图吗？

    不需要。本轮仅受理淘宝订单号，不上传截图，也不在本站付款。售后与退款请通过淘宝原订单联系商家，按原订单约定处理；本站只展示商家登记的状态，不会自动发起退款。

    如何查询已提交的订单？

    原浏览器可输入淘宝订单号或受理编号查询，也可使用提交后生成的完整私密查询链接。换设备需要私密链接；仅凭淘宝订单号不能在陌生设备查看资料。链接请妥善保存，不要公开分享。

    Session Key 提交错了怎么办？

    请通过淘宝原订单联系商家核实修改或撤销，支持时段为 9:00–23:00；不要在聊天或订单备注发送完整 Session Key，不要重复购买。不得提交他人账户的会话凭据。

    Session Key 会如何处理？

    Session Key 是登录会话凭据，持有者可能访问你的 Claude 账户。仅在确认淘宝订单约定的协助范围后提交；加密保存，仅授权审核员可查看。待核单超过 7 天将关闭并删除完整值；出结果 7 天后删除完整值，仅保留末 4 位。可通过淘宝原订单申请撤销与提前删除，并在 Claude 撤销相关会话。
