从正在使用的入口开始

说明你在哪个网站或应用中使用 Grok，以及目前看到的会员名称。不同入口的信息应分别核对，不凭相似名称推断权益相同。

如果咨询的是 SuperGrok 代充，把目标套餐和账号现有状态写清楚。准确名称比“高级会员”更有用。

月卡要明确实际期限

确认报价对应完整周期还是已有订阅的剩余期限，到期从何时开始计算，以及是否存在自动续费。月卡是期限描述，不是无限使用承诺。

使用量、模型和功能以实际套餐及账号页面为准。购买前留存双方确认的报价清单，交付后核对会员状态。

代充与独立账号的区别

方式先确认交付后核对
自有账号代充账号状态与可开通套餐原账号的订阅是否按约定生效
独立账号交付是否含会员、账号管理权限账号、会员和到期时间是否都正确

会员与 API 分开咨询

如果需要在程序中调用模型，应说明是 API 需求，并单独核实服务提供方、凭据、计费与限额。不要把会员月费当作 API 余额。

GetToken 当前以代充和独立账号咨询为主。没有明确报价的服务，不应从其他页面的介绍推断为已经可售。

付款前留下哪些信息

  • 产品入口和完整套餐名称。
  • 代充或独立账号，账号归属与管理范围。
  • 服务周期、总价、币种及续费方式。
  • 交付时效、异常处理、退款和售后边界。

常见问题

SuperGrok 月卡是不是无限使用？

不是。服务期限与用量是不同维度，需核对实际套餐、额度、重置规则和额外收费。

Grok 独立账号交付后查什么？

核对实际账号、是否含会员、到期时间、管理权限，以及后续续费与售后条件。
