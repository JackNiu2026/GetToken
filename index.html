FAQ

常见问题

如何购买？

在价格区选好方案后点击“扫码购买”，按弹窗中的收款码扫码付款，并在付款备注里填写弹窗显示的付款备注码。付款后把截图和备注码发给客服，核对完成即为你交付。

价格什么时候公布？

各方案价格即将公布。在此之前，下单金额以付款弹窗与客服确认的金额为准。

付款后多久可以交付？

目前采用人工核对，核对完成后会尽快交付。具体时效以客服确认为准，高峰时段可能稍有延迟。

三个产品有什么区别？

Codex 更适合代码工作，Claude 更适合长文档与深度内容，住宅 IP 面向跨境电商、AI 工具和多环境网络访问。你可以按当前工作目标选择，也可以组合使用。

应该选月付、季付还是年付？

第一次使用建议从月付或季付开始，确认适合自己的工作流后再选择更长周期。

为什么有人民币和美元两种币种？

账号类方案以人民币计价，住宅 IP 以美元计价。付款弹窗会明确显示金额、币种与可用的支付方式。

需要提供哪些信息？

无需注册账号。我们只需要付款备注码与付款凭证来核对订单，交付所需的信息由客服与你单独确认。

住宅 IP 的地区怎么选？

付款后，客服会与你确认所需地区与使用场景，再为你分配对应线路。

可以升级或更换方案吗？

可以联系客服说明你的需求，我们会根据当前方案与使用情况，为你说明可行的升级或更换方式。
