# SEO 指南库 /guides/

用户最新约束（2026-10-13）：首页保持不变；SEO 部分完全重构，按“今后内容会很多”的最佳实践设计。

## THESIS

内容库而不是单页：指南首页 → 产品专题页 → 文章页三层结构，文章是 Markdown 文件，专题、列表、分页、sitemap、RSS 自动生成。每个专题页承接一个产品主词，每篇文章只承接一个长尾意图。

## OWN-WORLD

沿用 GetToken Logo、深色画布、系统中文字体、白色胶囊按钮和蓝紫强调。指南有独立样式表 assets/guides/guides.css，不加载首页的 46KB 样式与脚本。每个专题有自己的强调色（tone），用于标记、标签、列表悬停与专题页头部光晕。

## STORY

搜索进入文章 → 先看导语给出的结论 → 目录跳读 → FAQ 与来源 → 相关阅读或专题页 → 首页套餐区。指南首页提供“新手先读”和按产品浏览两条入口。

## FORM

- 页头：Logo、“指南”入口、全部专题、查看套餐。
- 指南首页：面包屑、H1、导语、统计、新手先读；按产品浏览卡片（每张列出该专题 3 篇）；最近更新列表；常见问题；内容与更新原则；购买引导。
- 专题页：带专题色的页头（标记、H1、介绍、官方来源）、“购买前先分清”三条要点、全部文章列表（本专题在前、通用在后）、分页、其他专题、购买引导。
- 文章页：面包屑、专题标签、H1、导语、署名与更新日期、阅读时长；正文 + 右侧固定目录与购买卡；窄屏目录折叠到正文顶部；FAQ、来源、继续阅读、购买引导。
- 无运行时 JavaScript；关键内容全部在 HTML 中。
