## 先用真实账单确定基线

Claude Code 的固定订阅费、额外用量费和 API 账单应分别核对。先确认实际登录身份，再按相同任务和周期记录成本；工具中的估算金额不能代替最终发票，也不能把订阅内的估算 token 成本再加一次作为应付费用。

## 一张表算清总支出

| 项目 | 记录什么 | 计算方式 |
| --- | --- | --- |
| 固定费 | 完整周期、币种、税费、是否含账号 | 使用实际确认的总价 |
| 额外用量 | 已开启的额外消耗、预算和自动充值 | 采用对应账单，避免与固定费重复计算 |
| 服务费 | 已说明的服务项目和续费变化 | 只加明确列出的费用 |

同周期总支出 = 固定费 + 实际额外使用费 + 已确认服务费。API 或云路径则按对应账户的实际账单计算；附带 API credits 只有满足适用条件才可能抵扣。

## 示例：轻度与持续开发怎样比较

以下全是假设数字，不是本站报价或真实用户结果。用户甲一个月 API 支出 12 美元，无其他费用；若改用月付 Pro 的公开参考 20 美元，仅凭当前金额不能说订阅一定更省。用户乙每月固定费 20 美元、已确认额外用量 8 美元，总计 28 美元，不能只拿“20”与其他方案比较。

比较之前还需确认模型能力、任务是否可完成和限制是否可接受；同价不一定同服务。税费、地区与实时官方价格单独核实。

## 怎样记录而不泄露信息

在当前版本支持时查看 `/usage`；官方文档提醒会话成本是估算，订阅用户应看方案用量，API 用户以控制台账单为准。用同一周或月的实际任务建立基线，记录模型、工作时长、限额频率和额外收费，隐藏仓库、账号与密钥。

> 这里按公开文档整理，未在你的账号完成成本实测。不要用供应商平均值承诺你每天能完成多少任务。

## 升级前的检查

若经常触及订阅窗口且任务无法等待，再比较更高方案；若实际使用很少，不因“写代码”就默认从 Max 起步。购买月卡前确认接入方式、额度、预算上限、自动充值和续费，暂未受理时不要付款。

## 常见问题

### Claude Code 有会员还会产生 API 费用吗？

可能。先核对实际登录、API 凭据与计费页面，尤其检查是否设置了 ANTHROPIC_API_KEY。会员有效不能代替计费来源检查。

### Claude Code 月卡和 API 哪个更便宜？

要比较同一周期的真实固定费用、实际用量和额外收费。没有任务与账单数据，不能给出对所有人都适用的结论。
