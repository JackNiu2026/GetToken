当前额度先看这三个位置

  1. 在 Claude Code 当前支持版本中用 /help 确认命令，再查看 /usage；区分方案用量条、额外用量和会话估算，不把它们相加当作余额。
  2. 在 Claude 账号用量设置查看当前限额与重置；API 身份则看实际 API 组织或云平台账单和预算。
  3. 核对登录身份、方案和原购买周期；若本机设置了 API 凭据，不能只根据已买会员判断计费。

路径据官方文档整理，版本和权限不同会影响界面；本页没有使用你的账号实测。只提供脱敏提示，不能发送变量值、密钥或私人仓库内容。

用提示区分要等待还是要处理

提示或现象含义下一步
会话或周期用量已达上限期限内的用量窗口耗尽看明确重置时间，或在知情前提下评估额外使用
支出上限或预算不足额外用量/API/组织预算限制找到实际预算管理人，先核对账单
用量读取失败或旧快照当前数值可能并非最新按工具提示刷新，勿把缓存当作额度归零
上下文或压缩提示会话内容过长整理上下文，不直接认定需要续费

示例：还有二十天却无法继续

假设月卡还有效，但当前周期的使用窗口已耗尽。先记录工具显示的重置时间与时区；按重置条件等待后再试，而不是再买同一会员。若实际是 API 预算触顶，则应找对应计费账户处理，等待订阅重置不一定有效。

续费清单

确认账号与接入方、有效期、用量查询入口、重置规则、超额是否另收费、谁能修改预算。没有规则时不能承诺统一每日消息数；任务上下文、模型和工具使用都会影响消耗。异常持续且超过重置时间时，带脱敏提示联系实际提供方。

常见问题

Claude Code 月卡还有期限为什么仍被限额？

有效期与用量限制是不同条件。先查看实际用量、重置提示和预算，再判断是否需要续费或补充额度。

Claude Code 达到额度后一定要再充值吗？

不一定。可能可以等待重置，也可能涉及不同计费路径或环境配置；先查明限制来源。
