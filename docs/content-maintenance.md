# 内容与元信息维护

公开页面的分享图从 `content/site.mjs` 的 `shareImage` 取品牌回退图，`shareImages` 支持按规范路由覆盖。当前用已有 192×192 Logo 和 `summary` 卡片，明确标为品牌标识；不将它当作每篇文章的原创实测图。覆盖图需有权使用、与页面相关，声明尺寸须匹配实际文件；生成器检查本地文件和路径。

首页 SEO、共享导航、页脚和最新文章块均由构建器维护。正文视觉结构、样式和组件不受本轮元信息修改影响。其他页面直接编辑内容源，运行 `node scripts/build-site.mjs`，提交源和生成产物。

文章元数据：`updated` 是实质修改日期；可选 `verified` 是实际核对来源日期，不能晚于更新日；`published` 仅在有首次公开证据时填写。当前 13 篇缺乏可靠首次公开记录，继续省略 datePublished，不拿 Git 提交时间或本次更新日冒充首发日。也未伪造原创图片字段。

产品价格、资格和权益变动时，先更新 `content/product-facts.mjs` 与商品目录，再同步相关专题和文章。来源优先选择能直接支持结论的官方文档；记录适用地区、账号或版本。未在真实账号操作验证的路径应标明边界，不宣称已实测。

同义词不各建一页；商品负责询价与交付，专题负责问题分流，文章解答具体任务。标题、正文、canonical、内链、sitemap 与结构化数据必须一致。无真实报价不得填 Offer、评分、销量或库存。

发现错误时修正源文件并更新实质修改日期，保留必要的更正说明；不要定时改日期假装有新内容。每次发布保留构建与 HTTP 检查证据，搜索引擎收录、排名及真实网页性能需从相应平台另行观察。
