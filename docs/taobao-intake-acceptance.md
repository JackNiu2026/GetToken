# 淘宝订单提交流程验收

日期：2026-10-17。用户确认仅收淘宝订单号，本轮不接微信，不传截图。

- 前台：Session Key + 淘宝订单号 + 授权勾选 → 待人工核单 → 核单后处理 → 私密查询结果。移除在线付款选择、二维码、切换与续付操作；没有虚构商品链接。
- 后台：淘宝订单号搜索、人工核单与驳回、交付证据摘要、淘宝售后登记。提交不等于付款，售后登记不等于平台到账；没有假设淘宝金额与退款时限。
- 保留：布局容器、配色、所有 CSS、历史订单与财务补偿。新增输入复用现有表单组件样式；Session Key 长度上限改为 4096，支持实际较长会话值。
- 隐私：随机查询凭证、订单号 HMAC 去重、字段加密、公开尾号、受管备份同步清除；仅淘宝订单号不能跨设备访问。

CI 在合并后执行全站 HTML/SEO/部署版本检查，并通过只读 `/api/verify/config` 核验淘宝资料受理开放、站内支付渠道为空、没有假设交易金额。云端部署结果以 GitHub Actions 实际完成状态为准，此文档不预先声明上线。

运营操作见 [淘宝订单受理](external-order-intake.md)。没有淘宝商品链接不会影响已有订单提交；补充真实链接后可另加购买引导。

首次线上发布发现后台尚未满足资料受理条件，510 项网页检查通过但受理开放检查未通过。后续补齐缺失后台账号的私密初始化；已有密码与会话保持不变，显式暂停配置不会被覆盖。新增测试验证私有随机初始密码、哈希存储、幂等保留、已有文件及符号链接拒绝。
