## 先在自己账号里核对交付

Claude 订阅验收看三件事：正确账号、正确 Pro/Max 方案、正确有效期。GetToken 的 KYC 协助处理结果属于另一项服务，不能当作官方认证或会员已经生效的证明。

1. 登录约定的 Claude 账号，核对个人或团队工作区身份，避免只核对昵称。
2. 从账号设置进入方案或账单管理，确认套餐、周期和购买渠道；应用商店购买回原商店查记录。
3. 查看用量与重置提示；如使用 Claude Code，另查实际登录和 API 配置。菜单可能随版本变化，缺少入口时按下方官方账单说明核对。

## 用不同证据处理不同异常

| 现象 | 先确认 | 处理方向 |
| --- | --- | --- |
| 仍显示 Free | 是否登录了约定账号、开通是否完成 | 账号无误后要求支持方核查交付 |
| 方案正确但受限 | 用量、模型及重置时间 | 等待重置或按需评估用量，不重复购买会员 |
| 已买 Pro 仍有 API 费用 | Claude Code 的实际身份与 API 凭据 | 查看 API 控制台，不用会员页替代账单 |
| 到期时间不符 | 报价起算方式、原剩余周期 | 对照书面约定要求说明或处理 |

## 示例：Max 有效但编程暂时受限

示例用户在正确账号中能看到 Max，工具同时显示用量窗口已用完。这不能单独证明交付失败。应记录重置提示，在重置后复核；若是错误账号、错误方案或期限不足，则按交付约定处理。一次调用成功也不能保证未来永不受限。

## 验收记录与退款渠道

记录约定方案、交付时间、实际到期信息及脱敏状态；截图遮住邮箱、支付信息和凭据。额外用量、特定套餐附带的 API credits、订阅内用量分别查看。先核对原自动续费，避免同时被商家和官方渠道续费。退款或交付争议联系实际收款方，不把商家收据当作官方订阅凭证。

## 常见问题

### Claude Pro / Max 代充后怎样证明会员已生效？

在约定账号中核对实际套餐、状态和周期，并与报价清单比较。付款截图只能证明付款记录，不能替代权益核对。

### Claude 续费和升级有什么区别？

续费延长既有服务，升级改变套餐；实际周期、费用抵扣和生效方式需要在原账单渠道及报价中确认。
