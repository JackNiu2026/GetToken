    Claude KYC常见问题

    Claude 官方 KYC需要准备什么？

    官方通过 Persona 验证身份，需要有效的政府签发实体照片证件，可能还需用手机实时自拍。请按 Claude 账户内提示由本人完成；Session Key 是登录凭据，不能替代身份证件或完成官方身份认证。

    提交需要哪些资料？

    只需填写本人账户的 Session Key 并确认授权，不需要购买订单号或截图，本页不提供支付。

    提交后什么时候开始处理？

    提交成功后进入人工处理，预计 24 小时。超时仍显示处理中，不会自动判定通过；官方状态以 Claude 账户显示为准。

    如何查询已提交的记录？

    原浏览器可使用受理编号或最近提交记录查询；换设备请使用完整私密查询链接。链接请妥善保存，不要公开分享，不要在查询框输入 Session Key。

    Session Key 提交错了怎么办？

    请保留受理编号，通过已确认的支持渠道申请核实或撤销；不要在聊天中发送完整 Session Key。不得提交他人账户的会话凭据。

    Session Key 会如何处理？

    Session Key 是登录会话凭据，持有者可能访问你的 Claude 账户。仅在确认协助范围后提交；加密保存，仅授权审核员可查看。出结果 7 天后删除完整值，仅保留末 4 位。可申请撤销与提前删除，并在 Claude 撤销相关会话。

    如何找到 Session Key

    动画使用虚构界面与示例值，不会读取或复制你的 Cookie。

    可暂停、全屏观看，也可选择下方步骤跳转。

    查看文字步骤与 Mac 快捷键
    1. 登录 Claude，打开开发者工具

      在已登录的 claude.ai 页面按 F12。Windows / Linux 也可按 Ctrl+Shift+I；Mac 按 ⌘+⌥+I。

    2. 点击顶部的 Application（应用）标签

      在开发者工具顶部点击 Application（应用）。没有看到时，先展开顶部的 » 更多标签。

    3. 展开 Cookies，选择 claude.ai

      在左侧 Storage（存储）下展开 Cookies，点击 https://claude.ai，确认选中的是这个站点。

    4. 筛选并选中 sessionKey

      在 Filter（筛选）输入 sessionKey，选择 Name 恰好为 sessionKey 的行；不要选择 sessionKeyLC 等其他行。

    5. 复制完整的 Value（值）

      双击该行的 Value 单元格，按 Ctrl+A、Ctrl+C 复制完整值，再按 Esc 退出编辑。Mac 使用 ⌘A、⌘C；不要修改或删除 Cookie。

    6. 返回表单，粘贴后核对

      回到本站，在 Session Key 输入框粘贴完整值，只粘贴 Value，不要粘贴名称、截图或省略号。确认账户归属与授权范围后自行提交。

    只复制本人账号的完整 Value，不要复制 sessionKeyLC，不要照抄动画示例。Session Key 是登录凭据，请勿公开分享。
