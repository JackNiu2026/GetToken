购买 Claude 常见问题

代充和独立账号怎么选？

已经有 Claude 账号、想保留历史对话，选代充；没有账号或想把工作与个人分开，选独立账号。下单前与客服确认交付方式。

Claude Code 需要单独购买吗？

不需要。Pro 与 Max 都包含 Claude Code，区别在于可用的用量。主要用来写代码的话，建议从 Max 5x 起步。

付款后多久交付？

付款并发送凭证后，客服人工核对订单，确认后开始交付。交付完成后请在账号里核对套餐与有效期。

到期后怎么续费？

到期前联系客服续费即可，可以同时更换档位或周期，续费不影响账号里的对话和项目。
