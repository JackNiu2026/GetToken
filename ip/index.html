购买 住宅 IP 常见问题

地区怎么选？

付款后，客服会与你确认所需地区与使用场景，再为你分配对应线路。

三档线路有什么区别？

入门线路适合单一环境先用起来；生产线路适合日常多环境运营；旗舰线路适合长期运营、对稳定性要求更高的场景。

为什么用美元计价？

住宅 IP 以美元计价，付款弹窗会显示金额、币种与可用的支付方式。

可以升级线路吗？

可以联系客服说明需求，客服会根据当前线路与使用情况说明升级方式。
