购买 Codex 常见问题

代充和独立账号怎么选？

已经有 ChatGPT 账号、想保留历史对话和设置，选代充；没有账号或想把工作与个人分开，选独立账号。下单前与客服确认交付方式。

Codex 需要单独购买吗？

不需要。用 ChatGPT 账号登录 Codex 时，用量跟随账号当前的套餐，三档都可以使用 Codex。

订阅和 API 余额是一回事吗？

不是。订阅按账号套餐计算用量；API Key 走单独的计费账户，购买会员不会自动获得 API 余额。

到期后怎么续费？

到期前联系客服续费即可，可以同时更换档位或周期，续费不影响账号里的记录。
