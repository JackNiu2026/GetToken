# SOCKS5 订阅转换 /clash/

Mode: Operate.

继承 GetToken 的深色背景、系统中文字体、蓝色链接、白色主按钮、8px 表单圆角和 16px 工作区圆角。沿用全站八项导航，以“订阅转换”替换原“住宅IP”导航项；入口同时放在住宅 IP 页与共用页脚，不新增品牌或远程字体。

任务：用户批量粘贴 SOCKS5 / SOCKS5h 链接、Base64 SOCKS 分享链接、IP:端口:账号:密码或无认证的 IP:端口，选择 Clash 或小火箭后生成对应的 YAML 订阅，复制链接或唤起客户端，也可在本机下载文件。最多 100 个代理，包含 IPv6、名称、百分号编码与可选 UDP；小火箭输出独立 proxies 节点列表，不覆盖用户路由规则。错误定位到行，输入和错误提示不通过 URL 或日志传递。

电脑采用左侧输入、右侧订阅与 YAML 预览的两栏工作区；900px 以下堆叠，生成后将订阅滚入视图。空态直接显示格式说明；无 API 时保留本地下载。控件有标签、键盘焦点、加载和失败状态。示例仅使用文档保留地址。

生成前说明：本站加密保存配置 30 天，链接持有人能读取凭据。每次生成是一份快照，重新生成会撤销本页上一个链接；可主动使链接失效。刷新后的旧链接保留至到期，客户端已下载配置需自行删除。

系统文件复核：clash.css 使用 guides.css 与 chrome.css 的既有颜色、字体和圆角；不改 DESIGN.md 或 design.json。原有系统显示字体为继承视觉，不在本次扩展中重新定义。


导入引导优化：优先展示本地 YAML 下载，与远程订阅分开展示详细步骤；操作完成就地显示所选客户端的下一步。Clash 提供全部流量与局域网/中国大陆 IP 直连两种规则，默认保留全部交给 PROXY；GeoIP 依赖在选项旁说明。小火箭隐藏 Clash 分流控件并保留原路由设置。生成成功不能暗示代理认证或连通性已通过，FAQ 区分协议端口、凭据、超时与重置。仅使用文档保留地址验证流程。

手动组链：Clash 的连接方式提供“手动组链：前置和住宅节点放同一组”，展开前置 HTTPS 订阅字段。输出唯一“链式节点”组，同时列出住宅节点并 use 前置 provider；以“前置 · ”和“住宅 · ”区分，不隐藏或自动选前置，不预绑住宅 dialer。预览计数说明住宅数量加前置订阅，无法在网站得知前置节点数。操作完成后引导用户用客户端“链式代理”按前置在上、住宅在下组链；只选单节点不会串联。切换到直连/小火箭时不传递前置 URL，隐私提示覆盖前置订阅令牌。
