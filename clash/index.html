SOCKS5 订阅转换

将 SOCKS5 代理转换为 Clash 或小火箭配置。
下载 YAML 本地导入，或生成可在客户端导入的订阅链接。

如何导入

输入代理

支持 IP:端口:账号:密码、账号:密码@IP:端口、socks5://、socks5h:// 和 Base64 socks:// 分享链接。IPv6 地址需加方括号；URI 凭据中的特殊字符用百分号编码，冒号格式中的密码原样保留。

选择客户端后再生成。小火箭使用独立的 YAML 节点订阅，保留完整账号密码。

直连由本机连接 SOCKS5。入口需要中转时，选择链式代理。

仅支持 Clash Verge Rev / Mihomo。填写供应商提供的 HTTPS 节点订阅，优先选 Clash YAML（含 proxies 列表）；仅引用其他 provider 的配置、登录页及小火箭配置不适用。本站不读取订阅内容，也不验证其中节点。

Clash 每小时更新前置订阅；首次下载需要本机能直接访问该链接。前置加载后，“链式节点”组同时显示“前置 · ”和“住宅 · ”节点。点击客户端右上角“链式代理”，按前置在上、住宅在下的顺序组链并保存；仅选一个节点不会串联。前置订阅仍由客户端每小时更新。

分流在客户端的规则模式下生效。中国大陆 IP 直连使用 GEOIP,CN，需客户端具备可用的 GeoIP 数据库；不包含按域名分流。

生成订阅会将配置加密保存到本站 30 天。持有链接的人可读取代理凭据及前置订阅地址（可能含访问令牌），请妥善保管。下载 YAML 仅在本机处理。

两种导入方式

socks5:// 是代理节点链接，不是 Clash 的远程订阅地址。这里将它转换为 YAML；生成的 HTTPS 订阅链接用于下载这份配置。

不需要托管文件或上传到 Gist。仅在本机使用时，直接下载 YAML 即可。

方式一：本地文件导入

适合 Clash Verge，配置仅在浏览器本机生成。

  1. 下载 YAML

    填写代理信息，选择 Clash / Clash Verge，按需设置分流规则和 UDP，然后点击“下载 YAML，本地导入”。

  2. 新建 Local 配置

    打开 Clash Verge → 订阅 → 新建，类型选择 Local（本地），导入下载的 YAML 文件并保存。不同版本的入口名称可能略有差异。

  3. 启用配置并连接

    选中这份配置：直连配置在 PROXY 组选择节点（DIRECT 为直连）；手动组链配置在“链式节点”组同时显示前置与住宅节点，再用右上角“链式代理”按“前置 → 住宅”顺序配置并保存。然后开启“系统代理”，或按需开启 TUN；不要切换到另一份独立订阅。需要按上述规则分流时，请使用“规则”模式。

方式二：订阅链接导入

  1. 生成订阅链接

    选择客户端后点击“生成订阅链接”，本站会托管这次生成的 YAML 配置 30 天。

  2. 复制链接到客户端

    Clash Verge：在“订阅”页顶部粘贴 HTTPS 链接并导入；也可以点“导入 Clash Verge”。然后选中配置、选择节点并开启系统代理。

    小火箭：点击右上角“+”，类型选择 Subscribe / 订阅，粘贴链接并保存；也可点“导入小火箭”。选中订阅内的节点后连接，继续使用小火箭自己的路由设置。

链式代理如何设置、更新和排错？

选择 Clash 客户端和“链式代理”，填写前置节点订阅及住宅 SOCKS5，生成链接或下载 YAML 后一次导入。无需切换两份独立订阅。前置节点由客户端每小时更新，也可手动更新；住宅凭据和连接方式是生成时的快照，修改后需重新生成。

“链式节点”组同时列出前置订阅中的节点与住宅 SOCKS5，分别以“前置 · ”、“住宅 · ”区分。本站不隐藏或自动选择前置，也不预设住宅的 dialer-proxy。请使用客户端的“链式代理”功能，按顺序添加前置节点（入口、在上）和住宅节点（出口、在下），保存并启用代理链。只把节点放在同一组、或只选中其中一个，都不会自动形成代理链。

若同组中没有“前置 · ”节点，先等待订阅加载，并检查客户端日志中的 provider 下载或解析错误：确认链接在本机可直接访问，并返回当前 Mihomo 支持的节点内容。首次下载不经过住宅节点，避免循环依赖；只提供其他 provider 引用而不含节点的订阅不能直接使用。前置订阅更新后，如选中的前置已失效或被移除，请在客户端重新选择并保存链路；不要依赖旧的节点测速结果。建议使用带“链式代理”功能的 Clash Verge Rev v2.4.5 或更高版本。

导入成功，但代理连接失败怎么办？

导入成功只说明客户端读取到了配置，不代表代理可用。确认供应商后台选中 SOCKS5，并复制该协议对应的端口、用户名和代理密码；HTTP 和 SOCKS5 的端口可能不同，不能只改协议名称。若提示 User was rejected 或 authentication failed，先核对凭据和代理账户状态；超时或连接重置需检查线路及供应商的访问限制。Ping 无响应不能证明代理不可用。

UDP 和分流规则应该怎么选？

默认不启用 UDP；只有供应商明确支持 SOCKS5 UDP 转发时才勾选，链式代理还需前置节点支持 UDP。UDP 不会修复 TCP 连接或账号认证失败。默认将流量交给配置中的节点选择组，也可选择局域网及中国大陆 IP 直连。分流选项只作用于 Clash 配置，小火箭节点订阅不覆盖原有路由规则。

订阅和 YAML 文件可以分享吗？

两者都包含代理账号密码；订阅链接持有人可以读取凭据。不要公开上传到仓库、网盘或 Gist；secret Gist 仅隐藏列表，获得链接的人仍可读取。下载 YAML 仅在本机处理，生成本站订阅则会加密保存配置 30 天，但不为代理连接提供加密隧道。

如何更新或删除订阅？

每次生成的是配置快照，不会自动跟随供应商更新。修改代理或分流选项后，需重新下载文件，或生成新链接并在客户端替换。本页可用“使链接失效”撤销订阅，30 天后也会自动失效；这些操作不会删除客户端已下载的配置。
