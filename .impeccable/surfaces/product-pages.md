## MODE

Persuade：比较产品、选择需求，并理解当前是否受理。

## PATH

品牌介绍与官方参考 → 套餐 → 交付方式 → 意向周期 → 同步摘要与受理说明 → 办理/验收流程 → FAQ → 动态/指南。

## FORM

- 全站导航固定八项：首页、Claude订阅、Codex订阅、Gemini订阅、Grok订阅、KYC审核、住宅IP、AI新闻；最后一项指向 /guides/，导航居中。
- 首屏保留品牌标记、标题、介绍和官方资料。四个订阅页主操作进入方案区，副操作进入办理流程。
- 方案区左侧为原生单选组，三档沿用蓝、紫、绿强调；交付方式与周期各选一次。右侧固定摘要同步显示所选套餐、特性、交付、周期、金额与受理状态。
- 720px 及以下变为单列，摘要跟在全部选择后。菜单断点仍为 960px；窄屏菜单可纵向滚动。
- 住宅 IP 使用同一套选购布局（没有交付方式）。KYC 提交、查询和后台业务不变；后台只保留品牌与返回链接。
- 不增加支付、库存、成交量或客户评价。普通商品仍由配置决定是否受理；未报价显示“待报价”。

## DATA

档位/报价/交付源：assets/gettoken/catalog.mjs；受理状态：inquiry.mjs 与 site.config.mjs；商品事实：content/product-facts.mjs；文案：content/products.mjs。无脚本也可阅读所有档位，摘要标注默认方案并提示启用脚本；咨询不生成订单。
