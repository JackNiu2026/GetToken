# 已登录账户的 Session Key 助手

用户在桌面 Chrome / Edge 的同一份浏览器资料中已登录 Claude 时，扩展可经本人授权读取现有 `sessionKey`，无需重新登录、跳转 Claude 或打开 F12。读取成功仅表示当前 Cookie 存在且符合格式，不证明会话仍有效，也不证明身份认证通过。

## 用户操作

1. 普通入口 `/verify/` 输入框上方点击“获取已登录的 Session Key”。按钮注明测试版及原生读取待实机验收，未安装时显示安装说明和 ZIP 下载。无需添加查询参数，旧 `/verify/?helper=1` 链接仍可使用。
2. 解压安装包，访问 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式，加载包含 `manifest.json` 的目录。保持解压目录存在。
3. 刷新网站，重新点击获取按钮。扩展独立窗口显示读取来源、回填位置、登录凭据的访问能力和第三方关系。
4. 勾选本人账户授权，点击“授权读取并回填”；首次还需在浏览器权限提示中允许访问 Claude。
5. 回到网站核对输入框，再自行勾选网站提交授权并提交。扩展不勾选表单授权，不发起订单请求。

未找到 Cookie 时，在扩展窗口点击“打开 Claude 检查登录”；这会使用当前浏览器的资料，而非服务器浏览器。检查后可在两分钟内重试。过期、取消、关闭或导航来源页后需重新发起。

不支持手机浏览器、无痕窗口、其他浏览器资料、Firefox 和 Safari。受企业策略管理的浏览器可能禁止开发者模式。保留手动输入途径。

## 授权和数据边界

- Manifest V3，无第三方依赖或远程代码。`connect-src 'none'`；扩展无网络请求。
- 初始权限为 `cookies` 和 `storage`，Claude 主机访问按需申请。拒绝后不读取。
- 内容脚本仅在 `https://gettoken.cc/verify/` 的顶层文档运行；其他域名、后台、管理员页、子页面、iframe 和无痕环境均不接入。
- 只能由获取按钮的真实点击启动；网页消息仅用于探测和状态展示，不能要求读取。后台再次核对扩展身份、顶层帧、来源 URL、标签页和文档编号。
- 读取前需在扩展自己的页面明确授权。只读取指定名称 `sessionKey`；按来源标签页选择 Cookie store，不遍历其他 Cookie 值或自动猜测替代名称。
- 请求两分钟有效，绑定文档编号；导航、刷新、取消或过期后的请求不能回填。回填前再次确认输入框仍为空，防止覆盖后续手动填写。
- `chrome.storage.session` 只保存请求编号、来源标签页/文档编号、授权窗口编号及过期时间；从不保存 Cookie。凭据不进入日志、URL、剪贴板或 `window.postMessage`。
- 完整值只通过扩展内部消息进入隔离脚本，再直接写入指定输入框。页面代码此后可访问该值；提交后的服务端处理沿用现有规则。扩展无法保护被恶意脚本控制的目标网页，因此用户必须明确确认目标网站。
- 不读取或监控启动、Cookie 更新、后台定时事件；不自动提交、切换账号、完成官方身份认证或修改 Claude Cookie。
- 拒绝、失败或取消不修改输入框和网站授权；不会创建订单。

## 构建和发布

源码在 `extensions/session-helper/`。运行 `python3 scripts/package-session-helper.py` 生成可复现 ZIP，再运行 `node scripts/build-site.mjs`。CI 检查 ZIP 与源码一致，网站归档包含下载文件和网页接入脚本。

当前版本为 `0.1.0` 测试版，分发方式为开发者模式，不表示已通过 Chrome 或 Edge 商店审核。普通用户的一键商店安装需要由服务主体提交开发者账号、扩展隐私政策、图标和商店资料，并通过平台审核。不要伪造商店链接或声称已经上架。商店版发布后，网页通信不依赖固定扩展 ID，可沿用现有协议。

卸载扩展和撤销站点权限不等于撤销已提交的 Claude 会话；需要时用户应在 Claude 官方账户设置中撤销相关会话。

## 本轮验收边界

云端 Chromium 的管理策略为 `ExtensionInstallBlocklist: ["*"]`，不允许安装本扩展。保留该策略；未使用真实用户 Cookie，也未宣称完成真实浏览器扩展安装验收。

已通过后台授权/来源/过期/文档绑定测试，以及浏览器中使用模拟权限与凭据适配器的授权、取消、回填、草稿保护、无自动提交和桌面/移动端回退交互测试。模拟测试不能证明原生权限弹窗、Cookie API 和 Chrome/Edge 完整安装链路均已通过。

真实安装验收仍需在允许安装扩展的桌面浏览器中完成：安装并刷新网页；未勾选授权或拒绝浏览器权限时不回填；已有本人 Claude 登录时允许后能回填，网站提交勾选框保持未选；来源页面刷新、取消、过期和手动草稿均不会被旧请求覆盖。验收前应将本扩展视为待验证版本，勿宣称已通过商店审核或已完成真实账户测试。
