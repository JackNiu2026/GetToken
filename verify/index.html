    Claude KYC常见问题

    Claude 官方 KYC需要准备什么？

    官方通过 Persona 验证身份，需要有效的政府签发实体照片证件，可能还需用手机实时自拍。请按 Claude 账户内提示由本人完成；Session Key 是登录凭据，不能替代身份证件或完成官方身份认证。

    关闭页面或倒计时结束会怎样？

    关闭页面不影响本站订单处理，请使用原浏览器或保存的私密查询链接。24 小时是本服务的预计处理时间，不是 Claude 官方认证时限；超时仍会显示处理中，不会自动判定通过。

    认证协助未通过如何退款？

    本站订单未通过时，审核费 ¥300 在出结果后 24 小时内原路退回；人工技术费 ¥30 不退。退款进度在结果中显示。

    Session Key 提交错了怎么办？

    未开放时请勿输入。已付款后发现错误，请保留订单号并联系支持方核实，不要重复付款；不得提交他人账户的会话凭据。

    Session Key 会如何处理？

    Session Key 是登录会话凭据，持有者可能访问你的 Claude 账户。服务范围、撤销及提前删除处理方式未确认前不受理。开放后按约定用途加密保存，审核员可在后台查看；出结果 7 天后自动删除完整值，仅保留末 4 位用于识别。
