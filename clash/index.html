SOCKS5 转 Clash 订阅

粘贴代理信息，生成 Clash Verge 可导入的订阅链接。
也可以直接下载 YAML 配置文件。

如何导入

输入代理

支持 SOCKS5 链接、IP:端口:账号:密码、IP:端口。也支持域名和带方括号的 IPv6。链接中的特殊字符请使用百分号编码。

生成订阅会将配置加密保存到本站 30 天。持有链接的人可读取代理凭据，请妥善保管。下载 YAML 仅在本机处理。

Clash 配置

# 在左侧填入 SOCKS5 代理信息

在 Clash Verge 中使用

生成标准 Clash YAML，兼容 Clash Verge / Clash Verge Rev 的 Mihomo 内核。

  1. 粘贴 SOCKS5 信息

    支持带账号密码或无需认证的代理。“填入示例”使用文档保留地址，仅用于演示格式。

  2. 生成并复制订阅链接

    打开 Clash Verge 的“订阅”页面，将链接粘贴到订阅输入框后导入。也可以点击“导入 Clash Verge”唤起已安装的客户端。

  3. 选中配置与代理节点

    启用新配置，在 PROXY 分组选择节点，再开启系统代理或 TUN。配置默认将流量交给所选节点；选择 DIRECT 则直连。

只有 YAML 文件，怎么导入？

在 Clash Verge 的“订阅”页面新建本地配置并选择下载的 YAML 文件。静态预览没有订阅 API 时，也可以这样使用。

订阅链接和代理连接有什么区别？

订阅链接用于下载代理配置。转换不会检测代理连通性、改变 IP 所属地区或延长代理有效期；实际连接和 UDP 转发取决于代理服务本身。

如何更新或删除订阅？

修改代理信息后重新生成链接，再导入客户端。当前页面可使用“使链接失效”立即删除对应订阅；配置会在 30 天后自动失效。失效不会删除客户端已经下载的配置。
