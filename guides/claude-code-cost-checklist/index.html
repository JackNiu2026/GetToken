先用真实账单确定基线

Claude Code 的固定订阅费、额外用量费和 API 账单应分别核对。先确认实际登录身份，再按相同任务和周期记录成本；工具中的估算金额不能代替最终发票，也不能把订阅内的估算 token 成本再加一次作为应付费用。

怎样记录而不泄露信息

在当前版本支持时查看 /usage；官方文档提醒会话成本是估算，订阅用户应看方案用量，API 用户以控制台账单为准。用同一周或月的实际任务建立基线，记录模型、工作时长、限额频率和额外收费，隐藏仓库、账号与密钥。

升级前的检查

若经常触及订阅窗口且任务无法等待，再比较更高方案；若实际使用很少，不因“写代码”就默认从 Max 起步。购买月卡前确认接入方式、额度、预算上限、自动充值和续费，暂未受理时不要付款。
